# Terraform Azure Lab

## Objetivo
Aprender Terraform y Azure mediante ejercicios prácticos.

## Temas
- Infrastructure as Code (IaC)
- Terraform y HCL
- Providers y resources
- Autenticación con Azure
- Despliegue y administración de infraestructura

## Entorno
- Windows
- Visual Studio Code
- Git
- Terraform
- Azure CLI

## Seguridad
No publicar credenciales, secretos ni archivos de estado de Terraform que puedan contener información sensible.
